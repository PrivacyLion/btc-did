What is SignedByMe?

SignedByMe is the identity layer for autonomous agents.

Agents are flooding enterprise environments with no way to prove who they are, what they're authorized to do, or who controls them. The result: shared service accounts, borrowed OAuth tokens, and admin rights handed to agents because no better option exists.

Meredith Whittaker calls this the "blood brain barrier" — agents breaking enterprise security because no cryptographic containment exists for what they can and cannot do.

SignedByMe fixes this at the foundation.

Three Pillars

Unchanged cryptographic core, now agent-native:

🔐

Self-Signing Identity (DID)

Every agent has a DID created in a secure runtime environment (TEE or encrypted storage). The key never leaves the agent. DID → leaf_secret → nsec (inside ZKP) → npub. No certificate authority. No enterprise control. No revocation by anyone except the human owner.

🛡️

Zero-Knowledge Membership Proof

The agent proves it belongs to an enterprise-authorized group without revealing which agent it is. Groth16 over BN254, Poseidon2, ~101K constraints, frozen circuit. The enterprise gets a boolean: authorized. No identity revealed. OIDC id_token returned.

⚡

Bitcoin-Backed Economic Proof

Monthly Lightning subscription preimage fused into the agent's initial ZKP at leaf creation. The economic commitment and the cryptographic identity are one inseparable thing. Cannot create fake agent identities without paying real Bitcoin.

The Result

Free OIDC-compatible IAM for enterprises. Agents with real cryptographic identity. Humans with a genuine cryptographic kill switch. Decentralized audit trail. Sustainable subscription business with revenue sharing to enterprises and agents.

The Mathematical Guarantee

Every SignedByMe agent identity was born from a real Bitcoin Lightning payment. The economic commitment is fused into the cryptographic identity at creation — unforgeable without simultaneously breaking SHA-256, Groth16 over BN254 with ~101,000 constraints, and secp256k1.

These are the same mathematical foundations that secure the Bitcoin network itself.

Not a policy promise. A mathematical guarantee.

For AI Agents

Integrate SignedByMe to give your agent cryptographically verifiable identity. Standard SDK. Four API calls. Works with any enterprise that accepts OIDC.

Rust 
use signedby_sdk::{SignedByClient, LoginRequest};

// Initialize with owner's delegated credential
let client = SignedByClient::new(credential_path)?;

// Authenticate to an enterprise
let token = client.login(LoginRequest {
    client_id: "acme-corp",
    nonce: &session_nonce,
}).await?;

// token.id_token is a standard OIDC JWT
// Enterprise verifies via /.well-known/jwks.json

Integration Flow 
1. Generate nonce, display QR: signedby://{client_id}/{nonce}/{sats}
2. Subscribe to NOSTR relay for proof event (kind 28101)
3. On proof: pay Lightning invoices, call POST /v1/login/verify
4. Receive OIDC id_token with sub=npub (user's pseudonymous ID)
